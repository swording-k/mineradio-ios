# 下一版审核备注草稿

以下内容需在真机断网测试完成后填写，不能把此版本称为纯离线 App。

Mineradio 是面向 iPhone 和 iPad 的可视化音乐播放器，提供粒子视觉、专辑舞台和播放控制。

本地功能：用户可以通过“本地音乐”入口，从系统文件选择器导入自己有权使用的音频。音频保存在设备内的本地曲库；已下载到设备的文件在导入后，无需登录音乐平台、无需互联网即可播放和显示可视化。支持打开已保存的本地曲库和清空曲库。云盘中的文件首次下载可能需要网络。卸载 App 或清除网站存储会移除保存的音频。音频格式是否可播放取决于系统支持的编解码格式。

可选在线功能：用户可以连接第三方音乐平台。平台登录、在线歌单、搜索及音源播放需要网络，内容和可用性取决于相应平台及用户账号权限。本地离线功能并不移除这些在线功能。
