# 截图问题修复与汽水取流核实（2026-10-29）

## 已修正

- 手机登录页原来的整个 `.login-panel-head` 是绝对定位。只把“退出登录”子按钮改为 static 无效。本轮将头部整体纳入文档流，退出与关闭至少44pt，旋转提示排在头部后并缩短。
- 波点缺少输出端口，而且手机捕获点击走 `connectLoginProviderToMr → connectLoginMode` 后落入旧二维码路径。本轮补齐端口、连接与扫码路由。测试覆盖实际触控连接和 MR 扫码请求。
- 横屏歌单页的标签与操作按钮挤在一行，文字被压成多行。本轮分成操作行与不换行标签行；需要时横向滚动标签，不挤掉歌名。
- 汽水展开实际的 `seo_track.track`、候选先比时长再比码率、补 Web POST Referer，并在失败后用同 Web 身份参数 GET 重试。保留账号隔离与真实试听标记。

## 汽水60秒的明确边界

匿名实时探测《Flow Guilty》：整曲元数据204.723秒，SEO的PlayerInfo只有一条60.001秒M4A音源、无PlayAuth。此路径没有加密数据可供解码，原生解码器不能将60秒变成完整歌曲。

参考安卓的VIP直接取消trial标记不会增加实际音源时长，因此不照搬。当前新增Web取流重试可能影响已登录会员的PC接口请求，但尚无真实会员端到端证据，不能保证此曲原源整轨已恢复。脱敏探测证据在 `.inspect/qishui-flow-anon-result.jsonl`。
